Two-wavelength grating intensity, I(x)

Each wavelength interferes across the same set of grating tracks. The combined curve adds the two time-averaged intensities at each x.

Iλ = A₀² |Σn=0…N exp(iφn,λ)|²;  Iλ+Δλ = A₁² |Σn=0…N exp(iφn,λ+Δλ)|²;  Icombined = Iλ + Iλ+Δλ

Parameters

View window

Leave vertical half-span blank for automatic height. On log scale, each unit is one decade.

λλ + ΔλCombined
Move the pointer over the plot to inspect it.

Peaks in this window

Run a sweep to detect peaks.

Each wavelength is analyzed separately. Peak x is the midpoint of the outer top turning points in each region above its threshold. A dash means both turning points are not resolved.
